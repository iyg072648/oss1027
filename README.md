# 🎬 TubeHook - 유튜브 자막 기반 썸네일 & 제목 생성기

> **자막 파일만 넣으면 3초 만에 시청자와 알고리즘을 사로잡는 썸네일 문구 & 유튜브 제목 자동 생성기**

Lean Startup 철학에 기반하여, 크리에이터의 '제목/썸네일 짓기 고민'을 가장 빠르고 효과적으로 해결하는 초경량 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **다양한 자막 포맷 지원**:
   - 직접 텍스트 붙여넣기 (스크립트/대본)
   - `.srt`, `.vtt`, `.txt` 파일 드래그 & 드롭
   - 타임스탬프 자동 정제 및 텍스트 추출
2. **4가지 스타일별 최적화 추천**:
   - 💥 **자극/충격형** (CTR 극대화)
   - ❓ **호기심 유발형** (질문 및 미완성 문장)
   - 💡 **정보/솔루션형** (명확한 가치 및 꿀팁 제안)
   - 🎬 **스토리/반전형** (서사 및 비하인드 스토리)
3. **실시간 썸네일 캔버스 프리뷰**:
   - 16:9 비율의 유튜브 썸네일 레이아웃 실시간 시뮬레이션
   - 선택한 카피 문구 오버레이 및 배경 스타일 변경
4. **원클릭 복사**:
   - 마음에 드는 제목이나 썸네일 카피를 원클릭으로 클립보드에 복사
5. **AI 연동 & 로컬 모드**:
   - Google Gemini API 및 OpenAI API 키 직접 입력(BYOK) 지원
   - API 키가 없어도 작동하는 지능형 로컬 휴리스틱 분석 엔진 내장

## 🚀 빠른 시작

별도의 서버 설치 없이 브라우저에서 바로 실행할 수 있는 독립 실행형 웹 앱입니다.

1. 저장소 클론:
   ```bash
   git clone https://github.com/iyg072648/tubehook.git
   cd tubehook
   ```
2. `index.html` 파일을 브라우저로 열거나, 간단한 웹 서버를 실행합니다:
   ```bash
   npx serve .
   # 또는
   python3 -m http.server 3000
   ```
3. 브라우저에서 `http://localhost:3000` 접속
